# CASE-06

## Гипотеза руководителя

«Нам нужен агент, который каждую неделю собирает план визитов для полевых специалистов: кого посетить, в каком порядке и что проверить на точке».

## Короткий диалог

**Операционный директор:** Сейчас координатор вручную собирает план из приоритетов, расстояний, окон доступности и прошлых нарушений. План быстро устаревает, когда точка переносит визит.

**Продакт:** Какие данные уже есть в системе?

**Координатор:** Есть адреса, приоритеты точек, история проверок, доступные дни и комментарии специалиста. Но комментарии не всегда структурированы.

**Будущий пользователь:** Мне важно понимать, почему точка попала в план. Если система поменяет маршрут, специалист должен увидеть причину, а не просто новый список.

**Продакт:** Кто отвечает за финальное утверждение?

**Координатор:** Пока я. Автоматически назначать визиты без моего просмотра рано: иногда есть договорённости, которых нет в системе.
