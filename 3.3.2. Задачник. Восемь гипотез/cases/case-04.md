# CASE-04

## Гипотеза руководителя

«Хочу агента, который сам объясняет падение активации новых пользователей и предлагает продуктовой команде, что исправить в онбординге».

## Короткий диалог

**Директор продукта:** На прошлой неделе просела активация. Команда каждый раз собирает графики вручную, и обсуждение начинается слишком поздно.

**Продакт:** Какие события сейчас считаются активацией?

**Аналитик:** Есть три версии метрики. В дашборде одна, в квартальном отчёте другая, в экспериментальной панели третья. Ещё не решено, какую использовать для новых сегментов.

**Будущий пользователь:** Мне полезно быстро увидеть, где просадка: канал, сегмент, шаг онбординга или техническая ошибка. Но я не готов принимать продуктовые решения без проверки данных.

**Продакт:** Есть ли размеченные причины прошлых падений?

**Аналитик:** Частично. По крупным инцидентам есть заметки, но много случаев объясняли устно на встречах.
