Studio Shift — локальная операционная доска для команд, которые готовят помещения и оборудование к воркшопам. На одной странице координатор может попросить встроенного помощника показать открытую очередь, создать задачу или завершить выполненную работу.

Доска хранит операционные данные на текущем компьютере. Помощник использует модель AI Studio только для выбора одного из ограниченных локальных действий. В этом задании запрещено использовать исскуственный интеллект. У него нет доступа к shell-командам, внешним сервисам или данным клиентов.

## Требования

* Python 3.13;
* API-ключ AI Studio с правом вызывать текстовую модель;
* идентификатор папки, которой принадлежит выбранная модель.

## Локальная конфигурация

Приложение читает настройки из файла `.env` в корне проекта. Создайте его по `.env.example`, используя инструкцию для своей операционной системы.

Заполните в `.env` следующие значения:

* `YANDEX_AI_STUDIO_API_KEY` — секретный API-ключ;
* `YANDEX_FOLDER_ID` — несекретный идентификатор папки.

Значение `YANDEX_MODEL_ID` по умолчанию — `gpt-oss-120b`. Меняйте его, только если в вашей конфигурации AI Studio используется другая совместимая текстовая модель. Никогда не коммитьте, не передавайте и не вставляйте в запрос к помощнику файл `.env` или его содержимое.

## Windows

Откройте PowerShell в папке проекта Studio Shift.

Создайте виртуальное окружение и установите зависимости:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Создайте файл локальной конфигурации:

```powershell
Copy-Item .env.example .env
```

Заполните `.env`, затем запустите приложение:

```powershell
.\.venv\Scripts\python.exe app.py
```

## macOS

Откройте Terminal в папке проекта Studio Shift.

Создайте виртуальное окружение и установите зависимости:

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Создайте файл локальной конфигурации:

```bash
cp .env.example .env
```

Заполните `.env`, затем запустите приложение:

```bash
.venv/bin/python app.py
```

## Откройте доску

После старта локального сервера откройте в браузере `http://127.0.0.1:5000`. Чтобы остановить сервер, нажмите `Ctrl+C` в том же окне терминала.
